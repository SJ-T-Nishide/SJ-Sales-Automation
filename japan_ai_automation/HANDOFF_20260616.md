## セキュリティ設計

| 項目 | 実装 |
|---|---|
| Webhook認証 | `?secret=WEBHOOK_SECRET` クエリパラメータ検証 |
| CRM認証 | `assertAuthorized_()` — Google OAuth（Workspace限定） |
| APIキー | PropertiesService のみ（コード直書き禁止） |
| 配信停止ガード | `opted_out=true` は SequenceEngine・AlertEngine 両方でスキップ |
| email ユニーク | DB側ユニークインデックス `idx_leads_email`（PostgreSQL）|
| heat injection 防止 | `['A','B','C']` ホワイトリストで URL パラメータ生成前にフィルタ |
| doPost エラー | 外部には `"internal_error"` のみ返す。詳細は GAS ログ |
| 出席確認・配信停止 | SECURITY DEFINER RPC 経由（anon の直接 UPDATE 不可） |

## 技術仕様メモ

- GAS V8ランタイム（ES2020相当）。`require()` 不可・async/await 不要（同期）
- Supabase anon key を使用（RLSで制御）。service_role key は使わない
- メール送信: GmailApp（Brevo不使用）。無料500通/日・Workspace1500通/日
- シーケンス送信ロック: `claim_leads_for_sending` RPC が 8分ロック＋dedup_key で二重送信防止
- 実行時間上限: `MAX_EXECUTION_MS = 300000`（5分）。bulkEnrollLeads・Importer に適用
- `last_sequence_sent_at` でステップ間隔を計測（step2: 72h、step3: 168h）
