# エキスポ資料共有ゲート

Success Japan株式会社 GASプロジェクト v1.0

展示会でGoogle Slides資料をQRコード経由で配布するためのリード獲得フォーム。
名前・メールアドレス・電話番号を入力すると資料（Slides）がページ内に埋め込み表示される。
再訪問時は登録済みのメールアドレスまたは電話番号のどちらか一方を入力すれば再アクセス可能。

## 構成ファイル

| ファイル | 役割 |
|---|---|
| Code.gs | doGet・登録者シート管理・新規登録/再訪問チェックのロジック |
| Index.html | フォームUI（はじめての方／登録済みの方）＋Slides埋め込み表示 |
| appsscript.json | Webアプリ設定（access: ANYONE_ANONYMOUS, executeAs: USER_DEPLOYING） |

## 重要事項

- **本体はGoogleスプレッドシートに紐づくApps Script**（clasp管理・`clasp push`/`clasp deploy`でデプロイ）
- スプレッドシートの「登録者」シートが登録者データベース（名前・メール・電話番号・閲覧回数・最終閲覧日時）
- 対象のSlidesファイルは共有設定を「リンクを知っている全員：閲覧者」にしておく必要がある（埋め込み表示に必須）
- 閲覧回数・最終閲覧日時はシートの列として記録されるのみ。専用の閲覧・集計画面は未実装（スプレッドシートを直接開いて確認する）

## デプロイ方法

1. `clasp login --status` でログイン済みを確認
2. `clasp push` でコードをアップロード
3. `clasp deploy` でWebアプリとしてデプロイし、`/exec` URLを取得
4. 対象Slidesファイルの共有設定を「リンクを知っている全員：閲覧者」に変更
5. `/exec` URLをQRコード化して展示会で掲示
